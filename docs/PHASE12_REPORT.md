# ZAIDX FPS BOOSTER — Phase 12

Phase 12 adds native DXGI GPU inventory and a unified telemetry foundation.

## Added
- DXGI-based GPU enumeration.
- GPU name.
- Dedicated video-memory amount.
- Shared system-memory amount.
- GPU Info action in the native UI.
- Existing CPU/RAM history graph and safe Gaming Mode remain.

## Important limitation
This is GPU inventory/memory telemetry, not GPU utilization or temperature. Those metrics require additional vendor/system telemetry APIs and should be treated separately.

## Safety
No injection, anti-cheat bypass, memory modification, security disabling, persistence, driver manipulation, or license/trial bypass.
