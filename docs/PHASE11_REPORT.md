# ZAIDX FPS BOOSTER — Phase 11

Phase 11 adds a native Win32 performance-history graph window.

## Added
- Rolling telemetry graph for CPU and RAM history.
- Separate dashboard window.
- Existing history container remains capped at 60 samples.
- Existing Gaming Mode and read-only process telemetry remain.

## Safety
The dashboard only visualizes locally collected telemetry. It does not inject into games, modify game memory, bypass anti-cheat, disable security, create persistence, or bypass licensing.

## Note
The graph is a performance visualization, not an FPS counter. No fabricated FPS value is displayed.
