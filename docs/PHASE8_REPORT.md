# ZAIDX FPS BOOSTER — Phase 8

Phase 8 turns the selected-process telemetry into a lightweight live dashboard.

## Added
- Selected process CPU/RAM/thread metrics refresh every second.
- System information refresh remains on a separate two-second cadence.
- Fixed the Phase 7 source layout so the process telemetry functions remain inside the `zaidx` namespace.
- UI title and documentation updated for Phase 8.

## Safety
The telemetry is read-only. No DLL injection, game memory modification, anti-cheat bypass, process termination, persistence, security disabling, credential/token access, or license/trial bypass is included.

## FPS note
No synthetic FPS number is shown. A real FPS counter requires supported rendering telemetry or a transparent overlay/telemetry interface.
